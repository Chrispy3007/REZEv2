Settings

REZE AI Assistant · Provider-independent service

Set the HTTPS URL of your deployed Vercel AI endpoint. Provider API keys stay on the server and are never stored in this browser.

AI writing tools remain unavailable until a secure endpoint is configured. The sample library works without AI.

Groq AI · Hybrid resume parsing

REZE first extracts and classifies your resume in this browser. When you explicitly consent during an import, extracted text is sent to your Vercel API, which calls Groq. The original PDF/DOCX file is never sent to Groq.

Configure your deployed Vercel endpoint. The default example URL must be replaced with your actual deployment URL.

Store GROQ_API_KEY and GROQ_MODEL in Vercel Project → Settings → Environment Variables. Never add the key to GitHub, HTML, JavaScript, or browser storage. Use an HTTPS endpoint and restrict allowed origins to your REZE website.

Rules-based parsing always remains available. Groq is optional, runs only after per-import consent, and its suggestions must be reviewed before approval.
